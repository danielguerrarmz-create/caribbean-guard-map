# The Squarespace link card

The safety map is **not embedded** in the Squarespace site. Squarespace gets a
card that links out to it. This page has the image, the exact markup to paste,
and a no-code fallback for plans where Code Blocks are not available.

## Why a link and not an embed

Decided by Daniel, on the evidence in `docs/site-revamp/04-map-integration.md`:

- A Squarespace Code Block runs **inline in the page document**, not in a
  sandbox, so the map's CSS and JavaScript would collide with the theme's.
- **A service worker cannot register from a Code Block.** Squarespace will not
  serve `sw.js` at a usable scope, so the entire offline capability, which is the
  reason the map exists, dies on that path.
- The Squarespace page is **67 s to usable on Slow 3G against 7.8 s standalone**,
  a factor of 36, and the map is read on a beach.
- On **Basic and Personal plans, JavaScript and iframes are a premium feature**
  and visitors **silently see nothing**. Nobody has confirmed Caribbean Guard's
  plan.

A link card works on every plan, cannot fail silently, and the QR codes point at
the map's own URL anyway, so Squarespace was never gating the safety map.

## The image

`web/card.jpg`, 1200x630, 89 KB. It is a **real screenshot of the current
build**, not a mockup: generated by `tools/make_card.py` against the deployed
files, so it cannot drift into showing an interface that no longer exists.
Regenerate it whenever the map's appearance changes.

It deploys with the map, so it lives at `https://<map-url>/card.jpg` and needs no
separate upload. 1200x630 is the standard social preview ratio, so the same file
also works as an `og:image` later.

## What to paste

**Replace the two URLs if the subdomain is not set up.** They are the same
address twice. If `mapa.caribbeanguard.org` does not resolve yet, use the
Cloudflare Pages address instead, which looks like
`https://caribbean-guard-map.pages.dev`.

Add a **Code Block** to the page, set it to HTML, and paste this exactly:

```html
<!-- CARIBBEAN GUARD SAFETY MAP LINK. Do not delete.
     This is the link to the coastal safety map at mapa.caribbeanguard.org.
     It is the page QR codes on the beach signs point at. If it is removed,
     visitors lose the route to the map from this website.
     Questions: caribbeanguard.pv@gmail.com -->
<a href="https://mapa.caribbeanguard.org/" style="display:block;max-width:100%;text-decoration:none;color:#0b1c2c;font-family:inherit;border:1px solid #d5dbe1;border-radius:12px;overflow:hidden;background:#ffffff">
  <img src="https://mapa.caribbeanguard.org/card.jpg" alt="Mapa de seguridad costera de Caribbean Guard, de Puerto Viejo a Manzanillo" width="1200" height="630" style="display:block;width:100%;height:auto;border:0">
  <span style="display:block;padding:14px 16px;font-size:17px;font-weight:700;line-height:1.35">Mapa de Seguridad Costera<span style="display:block;font-size:14px;font-weight:400;color:#5b6b7a;margin-top:4px">De Puerto Viejo a Manzanillo. Funciona sin señal. Abrir el mapa →</span></span>
</a>
```

Notes on why it is written that way:

- **No JavaScript, no iframe, no `<style>` block.** Everything is an inline
  `style` attribute on the element it applies to, so nothing depends on the
  theme's CSS and nothing can leak into it. This is what makes it work on Basic
  and Personal.
- **One top-level element.** The Squarespace sanitiser reorders attributes and
  mangles markup that looks like it escapes the block, so there is one `<a>` with
  two children and no wrapper divs.
- `width` and `height` are on the `<img>` as attributes as well as in the style,
  so the browser reserves the right space before the image loads and the page
  does not jump.
- The `alt` text describes the map, so if the image fails to load the link still
  says what it is.

## If Code Blocks are not available on the plan

Code Blocks require Business or higher. On Personal or Basic, build the same
thing from native blocks, which needs no code and works on every plan:

1. Add an **Image Block**. Upload `web/card.jpg`.
2. In the image's settings, set the **Clickthrough URL** to the map address.
3. Set the caption to: *Mapa de Seguridad Costera. De Puerto Viejo a Manzanillo.
   Funciona sin señal.*
4. Add a **Button Block** underneath, label **Abrir el mapa de seguridad**,
   linked to the same address.

The button matters: some visitors do not know an image is clickable, and on a
safety page that is not a detail to leave to chance.

## Where it should go
